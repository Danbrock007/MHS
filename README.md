# MHS School Fees Management v3

Premium offline Flutter mobile application for Faisalabad Mesali High School.

Login: Dilshad / Dilshad@123

Features include responsive premium glass UI, remember-me login, student and sibling management, automatic sibling grouping by father name and father CNIC, class-wise students, multi-month/class/student/year voucher generation, custom invoices, payments, history, PDF/image sharing, reports, Excel/PDF export, settings and SQLite backup.
